## 💻 핵심 코드 분석

### 임계값 기반 감지

```lisp
(def alert-thresholds {
  "page-load" 2000  ; 2초 이상
  "api-call" 1000   ; 1초 이상
  "memory" 80       ; 80% 이상
  "long-task" 500   ; 500ms 이상
})

(defn detect-performance-alert [$record]
  (let [$metric (get $record "metric")
        $value (get $record "value")
        $threshold (get alert-thresholds $metric)]
    (if (and $threshold (> $value $threshold))
      (let [$severity (if (> $value (* $threshold 1.5)) "high" "warning")]
        ; 알림 생성
        ...))))
```

**특징**:
1. **유연한 정의**: map으로 임계값 관리
2. **자동 심각도**: value > threshold*1.5 시 "high"
3. **타입별 지원**: page-load, api-call, memory, long-task

### SSE 구현

```javascript
const es = new EventSource('/api/alerts/stream');

es.addEventListener('message', (e) => {
  try {
    const alert = JSON.parse(e.data);
    this.alerts.unshift(alert);
    this.render();
  } catch (err) {
    console.error('Parse error:', err);
  }
});

es.onerror = () => {
  document.getElementById('dot').style.background = '#dc3545';
  document.getElementById('status').textContent = '연결 끊김';
};
```

**매커니즘**:
- EventSource로 일방향 푸시
- JSON 파싱 → 즉시 UI 업데이트
- 연결 상태 표시 (dot animation)

### 심각도 시각화

```javascript
const alertHTML = this.alerts.map(a =>
  '<div class="alert ' + a.severity + '">' +
    '<div class="severity">' + a.severity + '</div>' +
    '<span class="metric">' + a.metric + '</span>' +
    '<span class="threshold">' + a.value + 'ms / ' + a.threshold + 'ms</span>' +
    '<div class="message">' + a.message + '</div>' +
  '</div>'
).join('');
```

**색상**:
- `alert.high`: 빨강 (높은 우선도)
- `alert.warning`: 노랑 (주의)
