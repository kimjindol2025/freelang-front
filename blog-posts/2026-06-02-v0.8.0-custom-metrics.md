### 1. 메트릭 메타데이터 저장소

**파일**: `performance-monitor.fl` (업데이트, +75줄)

```lisp
; 커스텀 메트릭 정의
(defn create-custom-metric [$name $description $unit $threshold]
  (let [$id (str (random))
        $metric {
          "id" $id
          "name" $name
          "description" $description
          "unit" $unit
          "threshold" $threshold
          "created-at" (str (date-now))
          "records" 0
        }]
    (swap! custom-metrics assoc $id $metric)
    $metric))
```

**특징**:
- 메트릭별 고유 ID
- 단위(unit) 지원 (ms, %, count 등)
- 임계값 선택적 지정
- 생성 시간 기록

### 2. 메트릭 기록 함수

```lisp
(defn record-custom-metric [$metric-id $value]
  (let [$record {
    "id" $metric-id

    ; 저장소에 추가
    (swap! custom-metric-data ...)
```

**특징**:

### 3. 메트릭 API

**파일**: `pages/api-custom-metrics.flx`

```lisp
; POST /api/custom-metrics (메트릭 생성)
(defn handle-create-custom-metric [$req]
  (let [$body (get $req "body")]
    (let [$metric (create-custom-metric 
      (get $body "name")
      (get $body "description")
      (get $body "unit")
      (get $body "threshold"))]
      (server-json $metric 201))))

; GET /api/custom-metrics (메트릭 목록)
(defn handle-list-custom-metrics [$req]
  (let [$metrics (get-custom-metrics)]
    (server-json {
      "total" (length $metrics)
      "metrics" (values $metrics)
    } 200)))

; POST /api/custom-metrics/record (데이터 기록)
(defn handle-record-custom-metric [$req]
  (let [$body (get $req "body")]
    (let [$record (record-custom-metric 
      (get $body "metric-id")
      (parse-float (get $body "value")))]
      (server-json $record 200))))

; GET /api/custom-metrics/data (데이터 조회)
(defn handle-get-custom-metric-data [$req]
  (let [$query (get $req "query")
        $limit (parse-int (or (get $query "limit") "50"))]
    (let [$data (get-custom-metric-data 
      (get $query "metric-id") $limit)]
      (server-json $data 200))))
```

**엔드포인트**:
- `POST /api/custom-metrics` — 메트릭 생성 (201)
- `GET /api/custom-metrics` — 메트릭 목록 조회
- `POST /api/custom-metrics/record` — 데이터 기록
- `GET /api/custom-metrics/data?metric-id=X&limit=50` — 데이터 조회

### 4. 메트릭 관리 대시보드

**파일**: `pages/dashboard/custom-metrics.flx`

```javascript
const CustomMetrics = {
  metrics: {},
  init() {
    this.loadMetrics();
  },
  loadMetrics() {
    fetch('/api/custom-metrics')
      .then(r => r.json())
      .then(d => {
        this.metrics = d.metrics || [];
        this.render();
      });
  },
  render() {
    const container = document.getElementById('metricsContainer');
    container.innerHTML = this.metrics.map(m => 
      '<div class="metric-card">' +
        '<div class="metric-name">' + m.name + '</div>' +
        '<div class="metric-unit">' + m.unit + '</div>' +
        '<div class="metric-threshold">임계값: ' + (m.threshold || '-') + '</div>' +
      '</div>'
    ).join('');
  }
};

function createMetric() {
  const name = document.getElementById('metricName').value;
  const desc = document.getElementById('metricDesc').value;
  const unit = document.getElementById('metricUnit').value;
  const threshold = document.getElementById('metricThreshold').value;

  fetch('/api/custom-metrics', {
    method: 'POST',
    body: JSON.stringify({name, description: desc, unit, threshold})
  })
  .then(r => r.json())
  .then(d => {
    CustomMetrics.loadMetrics();
  });
}
```

**특징**:
- 메트릭 생성 폼
- 활성 메트릭 카드 표시
- 단위 명시
- 임계값 표시

## 💻 핵심 코드 분석

### 유연한 메트릭 관리

```lisp
; 메타데이터만 저장
(def custom-metrics (atom {}))
{
  "uuid-1" {
    "id" "uuid-1"
    "name" "로그인_시간"
    "unit" "ms"
    "threshold" 5000
  },
  "uuid-2" {
    "id" "uuid-2"
    "name" "오류율"
    "unit" "%"
    "threshold" 5
  }
}

; 기록은 별도
(def custom-metric-data (atom []))
[
  {"id" "uuid-1" "value" 1200 "timestamp" "..."}
  {"id" "uuid-1" "value" 3400 "timestamp" "..."}
  {"id" "uuid-2" "value" 2.3 "timestamp" "..."}
]
```

**장점**:
- 메타데이터와 데이터 분리
- 메모리 효율성
- 쿼리 속도 향상

### 임계값 자동 감지

```lisp
(defn record-custom-metric [$metric-id $value]
  (let [$metrics (deref custom-metrics)
        $metric (get $metrics $metric-id)]
    (if (and (get $metric "threshold") (> $value (get $metric "threshold")))
      (let [$alert {
        "type" "custom"
        "metric" (get $metric "name")
        "value" $value
        "threshold" (get $metric "threshold")
        "severity" (if (> $value (* (get $metric "threshold") 1.5)) "high" "warning")
      }]
        (swap! alert-log conj $alert)))))
```

**매커니즘**:
1. 데이터 기록 시 자동 감지
2. 임계값 초과 여부 판단
3. 심각도 계산 (1.5배 초과 → high)
4. 알림 저장소에 추가
