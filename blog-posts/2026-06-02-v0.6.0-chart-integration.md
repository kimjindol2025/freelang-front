## 💻 핵심 코드 분석

### 차트 생성 함수

```javascript
createChart(canvasId, label, data, color) {
  const canvas = document.getElementById(canvasId);
  if (!canvas) return;
  
  const ctx = canvas.getContext('2d');
  const labels = data.map((r, i) => i + 1);
  const values = data.map(r => parseFloat(r.value));
  
  // 기존 차트 제거 (메모리 누수 방지)
  if (this[canvasId]) this[canvasId].destroy();
  
  // 새 차트 생성
  this[canvasId] = new Chart(ctx, {
    type: 'line',
    data: {
      labels,
      datasets: [{
        label,
        data: values,
        borderColor: color,
        backgroundColor: color + '20',
        tension: 0.4,
        fill: true
      }]
    },
    options: {
      responsive: true,
      maintainAspectRatio: false,
      plugins: {
        legend: { display: true }
      },
      scales: {
        y: { beginAtZero: true }
      }
    }
  });
}
```

**주요 포인트**:
1. **메모리 관리**: `destroy()` → 재생성 패턴
2. **반응형**: `responsive: true` + `maintainAspectRatio: false`
3. **데이터 처리**: 최근 20개만 필터링
4. **색상**: 동적 색상 지정 (파라미터)

### 실시간 데이터 로드

```javascript
loadData() {
  fetch('/api/metrics')
    .then(r => r.json())
    .then(d => {
      const records = d['recent'] || [];
      this.renderCharts(records);
    });
}
```

**매커니즘**:
- 기존 `/api/metrics` 엔드포인트 재사용
- 최근 데이터만 추출
- 즉시 그래프로 렌더링
