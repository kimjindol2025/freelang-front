## 🔍 v0.4.0의 배운 점

### ❌ HTML in FreeLang Server의 함정

FreeLang의 `server_html`에 큰 HTML을 문자열로 전달할 때:

```lisp
; ❌ 이 방식은 끝내 실패함
(defn render [$req]
  (server_html 
    "<html><body>...</body></html>"))
```

**문제점**:
1. 파서가 큰 따옴표 안의 괄호도 추적
2. HTML의 `onclick="func()"` 같은 부분이 파서를 혼동
3. 심지어 이스케이프된 따옴표(`\"`)도 추적됨

### ✅ 더 나은 접근법들

#### 방법 1: 간단한 상태 페이지
```lisp
(defn render [$req]
  (let [$data (get-stats)]
    (server_html 
      "<h1>Stats: " (str $data) "</h1>")))
```

#### 방법 2: 별도 파일 로드
```lisp
(defn render [$req]
  (let [$html (file_read "public/dashboard.html")]
    (server_html $html)))
```

#### 방법 3: API-only 아키텍처
```lisp
; Backend: /api/metrics, /api/metrics/filter 제공
; Frontend: 별도 static HTML이 API 구독
```

**우리가 선택한 방식**: **방법 3 (API-only)**
- 백엔드: 순수 API 제공
- 프론트: 별도 대시보드 HTML (v0.5.0에서 최적화된 형태로)
- 장점: 관심사 분리, 테스트 용이, 확장성 극대화

## 🎯 v0.5.0 준비 사항

### 1. 대시보드 페이지 구조

```
pages/
  _dashboard/
    index.flx          # 대시보드 메인
    components/
      stats.flx        # 통계 카드
      table.flx        # 메트릭 테이블
      filters.flx      # 필터 패널
```

### 2. 클라이언트 스크립트

```javascript
// 실시간 업데이트
const stream = new EventSource('/api/metrics/stream');
stream.addEventListener('metric', (e) => {
  const record = JSON.parse(e.data);
  updateTable(record);
  updateStats();
});

// 필터링
async function filter(metric, hours) {
  const res = await fetch(`/api/metrics/filter?metric=${metric}&hours=${hours}`);
  const data = await res.json();
  renderTable(data.data);
}

// 내보내기
async function export(format) {
  const res = await fetch(`/api/metrics/export?format=${format}`);
  const blob = await res.blob();
  downloadFile(blob, `metrics.${format}`);
}
```

## 💡 개발자 경험 개선 (v0.4.0)

### 클라이언트 스크립트 안정화

```javascript
// ✅ v0.4.0에서 추가할 개선사항
function recordMetric(metric) {
  // 1. 재시도 로직
  const MAX_RETRIES = 3;
  for (let i = 0; i < MAX_RETRIES; i++) {
    try {
      await fetch('/api/metrics', { method: 'POST', body: ... });
      return;
    } catch (e) {
      if (i === MAX_RETRIES - 1) throw e;
      await sleep(100 * Math.pow(2, i)); // 지수 백오프
    }
  }
  
  // 2. 에러 로깅
  if (navigator.sendBeacon) {
    navigator.sendBeacon('/api/metrics/error', JSON.stringify(e));
  }
}
```
