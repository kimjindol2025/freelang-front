## 💻 핵심 코드

### SLO 자동 검증

```lisp
; 매 기록 시 자동 검증
(record-performance $metric)
  ↓
(check-slo-compliance $metric $value)
  ↓
(sla-tracking update)
```

### 준수율 계산

```
성공 = value <= threshold
준수율 = (성공 수 / 총 수) * 100

페이지로드 예:
- 100개 요청 중 96개 < 3초
- 준수율 = 96/100 * 100 = 96%
- SLO 목표 = 95%
- 상태 = ✓ 준수
```
